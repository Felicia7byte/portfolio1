02 / NATURAL LANGUAGE PROCESSING

AI Translation

An AI-powered translation application built with Streamlit and Hugging Face Transformers using the NLLB-200 multilingual translation model. The application allows users to select source and target languages, enter text, and generate translations through an interactive web interface. It currently supports five languages: English, Indonesian, Chinese, Japanese, and Korean.
